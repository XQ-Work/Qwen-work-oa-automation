# 脚本运行前规范操作

## 一、文件投放位置

所有待整理的文件请放入以下文件夹：

```
D:\自动备份\WorkBuddy\文档整理\整理中\
```

整理完成后此文件夹会被清空，下次使用前为空状态。

---

## 二、文件命名建议（核心规则）

**文件名越清晰，归类越精准。** 建议在文件名中包含项目线索：

| 命名方式 | 示例 | 效果 |
|---------|------|------|
| 文件名带项目名+文档类型 | 事项审批（变频器）.pdf | 自动识别项目和类别，无需OCR |
| 文件名带供应商名 | 供应商报价单及资质（细格栅维修）.pdf | 自动归入对应项目的报价文件夹 |
| 纯扫描件无文件名线索 | DocumentScanner_xxx.pdf | 需OCR识别内容，耗时且可能不确定 |
| 合并PDF含多种文档 | 比质比价单、供应商报价单及资质（滤布）.pdf | 自动拆分后分别归档 |

**最佳实践：** 放入文件前，按 `文档类型（项目名）` 或 `文档类型_项目名` 的格式重命名。

---

## 三、文档分类标准

归类依据文件名中的关键词：

| 关键词 | 归入类别 | 
|-------|---------|
| 事项审批、申购单、审批 | `01_事项审批` |
| 报价单、供应商报价、营业执照、身份证、资质 | `02_供应商报价及资质` |
| 比质比价报告单、比价单、比价 | `03_比质比价报告单` |
| 采购合同、服务合同、服务协议、合同 | `04_采购合同` |
| 发票、付款单、流程会签、已用印合同、验收、回单 | `05_付款及验收` |
| 照片、方案、图纸、其他非标准材料 | `06_其他`（自由区，不进必传核对） |

---

## 四、支持的格式

| 格式 | 说明 |
|------|------|
| `.docx` / `.doc` | 读取正文文字识别内容 |
| `.pdf` | 文本PDF直接提取；扫描件自动OCR识别中文 |
| `.jpg` / `.png` | 直接进行OCR文字识别 |
| `.xlsx` / `.xls` | 读取表格内容（暂未启用） |

---

## 五、重复文件处理规则

遇到 `.docx/.doc` 与 `.pdf` 内容重复时：

- ✅ **两种格式同时保留**，不删除任何一版
- .docx/.doc 保留作为可编辑版
- .pdf 保留作为正式/盖章版

---

## 六、合并PDF处理规则

当单个PDF包含多页不同类别的内容时（如第1页比质比价报告单、第2-7页供应商报价单）：

- 系统会先对每页做OCR识别，判断页面归属
- 按页面范围拆分为独立文件
- 分别归入对应的类别文件夹

---

## 七、无法归属文件的处理

当文件名无线索、OCR也无法确定项目归属时：

- 文件会移入 `待确认\` 文件夹
- 台账不会更新该文件
- 你手动确认后，可再次放入 `整理中\` 由系统归档

---

## 八、每次整理的输出产物

归档完成后，系统自动生成/更新以下文件：

| 文件 | 位置 | 用途 |
|------|------|------|
| **采购项目台账.xlsx** | 采购项目档案\ | 总索引，含中标供应商、金额、归档状态等 |
| **项目文件目录.xlsx** | 各项目文件夹内 | 单个项目的文件清单（文件名、类型、大小） |
| **文档总目录.xlsx** | 采购项目档案\ | 全部项目的汇总 + 全部文件明细 |
| **归档记录_YYYY-MM-DD.xlsx** | 采购项目档案\ | 本次整理的文件去向记录（源→目标） |

---

## 九、一句话总结

```
文件放入 整理中\ → 找我 → 我自动归类归档 → 更新台账和目录 → 输出归档记录
```

你只需要做：**把文件丢进"整理中"文件夹，告诉我"帮我整理"**。
