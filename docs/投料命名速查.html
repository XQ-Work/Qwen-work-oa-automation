投料命名速查

材料丢进「输入/」就一个规则：材料名（事项名）.pdf。点虚线框可复制示例。

一、总格式

材料名(事项名).pdf 复制示例
  • 事项名 = 项目文件夹「2026-NNN-」后面的那几个字，如 潜污泵采购 → 事项名 潜污泵采购
  • 可带金额（系统用它自动分流 2000 上下两条道）：
    申购单（潜污泵采购-金额：1500）.pdf 复制
  • 全角半角括号都认；多份同材料在事项名后加说明字：
    事项审批（发电机排涝）.pdf + 事项审批（发电机排涝）排涝物资.pdf → 全部一起上传 复制
  • 新事项第一刀永远投申购单；没在台账里的事项会自动建夹、自动编号

三、这些不用改名，直接丢进「输入/」

  • 电子发票：dzfp_2642200000… → 自动识别分流
  • 银行回单：文件名含 回单 / 交易流水 / 银行流水 → 自动进回单扫描线
  • 入库单：入库单扫描件_ 开头 → 单据线自动分拣归位

四、日常三句话

收料：把材料丢进 输入/，说一句“收料”（= intake_all.py run） 发草稿：攒几单后说一句“发草稿”（= flush，永远只到草稿，提交人工） 看进度：打开根目录 进度总览.xlsx（一行一事项，缺的附件标红点名）
  • 命名不规范的 → 进 工作/复核/收件异常，改名后重投
  • 办结了 → 跟助理说“归档 2026-XXX”（自动分 日常采购 / 采购合同）
  • 回单到账 → 直接丢输入/，自动匹配归到项目 05 夹

五、正反例对照

✗ 合同.pdf　｜　✗ 合同(事项名).docx　｜　✗ 采购合同（2026-005-发电机排涝采购）.pdf
原因：缺事项名 / 用了材料旧格式 / 事项名写成完整文件夹名（去掉编号前缀）
✓ 采购合同（发电机排涝采购）.pdf　　✓ 申购单（空压机采购-金额：8200）.pdf

六、常见疑问

  • 同一个材料要传两个流程怎么办？不用复制，交一次放对位置即可（如采购合同=会签原件+付款侧另给已用印版）。
  • 发票要不要改名？要：给 OA 挂附件的 发票（事项名）.pdf；纯电子记账可丢 dzfp 原件。
  • 事项名不知道填什么？打开 进度总览.xlsx 看事项列，照抄；或问助理。
  • 新事项还没有编号？第一刀投 申购单（事项名），系统建夹自动编号。
  • 批量来料？一次性全丢输入/，说一句“收料”即可。
