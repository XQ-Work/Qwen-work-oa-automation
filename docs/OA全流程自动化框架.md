# OA 全流程自动化框架（2026-09-29 五层版）

## 一句话

材料丢进 `输入/`，系统按“材料名（事项名）”分流归位、建档索引；攒批生成 OA 草稿（永远人工提交）；钱、货、单、证全程留痕，进度总览一表看全，办结自动归档。

## 工作区五层

```
输入/   唯一投料口（平铺）。规范名=材料名（事项名）.pdf；未按命名的按词头自动分流
工作/   流水线在途：单据(入库→验收→付款) · 银行回单(扫描→核对→已确认) · 复核(人工异常件)
记录/   留痕：台账(发起台账+交付/归档台账主份) · 数据库(主档/文档索引) · 项目档案(2026-NNN，01~06阶段子夹)
系统/   oa-automation(全部代码) · docs · 模板(01申购~04流程表单) · 运行(浏览器登录态+state)
交付/   成品副本，只收PDF：同事项多件自动合并一册、日期前缀，打印送签用
归档/   办结收纳：日常采购(<2000) · 采购合同(≥2000)，卡片式归档台账
根      进度总览.xlsx（系统自动重建，永远最新）
```

## 业务主链

```
申购需求 → 申购单(M02) → 比质比价(M03) → 事项审批(M01,475401) ─┬ ≥2000 → 合同会签(M05,476402) → 付款申请(M06,486901) ─┐
                                                              └ <2000 →（免合同）付款申请(M06) ────────────────────┤
新供应商首次合作 → 供应商新增(M04,444401)（并行）              银行回单(M07 扫描匹配归档) → 办结 → archive 归档
```

## 常用命令（都在 系统/oa-automation 下）

| 场景 | 命令 |
|---|---|
| 收料归档+排队 | `python intake_all.py run` |
| 攒批发草稿 | `python intake_all.py flush`（可 `--only m05,m06`） |
| 看队列/异常 | `python intake_all.py status` |
| 项目齐套核对 | `python intake_all.py verify --project 2026-NNN` |
| 单据流水线 | `python danju/adapter.py run`（flush 自动带） |
| 回单匹配归档 | `python modules/m07_receipt/match_archive.py`（先 --dry-run） |
| 金额对账 | `python -m oa_common.moneyline report` |
| 全文检索附件内容 | `python -m oa_common.docindex search 关键词 [编号]` |
| 手工刷新总览 | `python -m oa_common.dashboard` |
| 归档 / 取出 | `python intake_all.py archive --project 2026-NNN [--undo]` |

## 铁律

1. 工具只到草稿，提交永远人工；2. 密码只进 Windows 凭据管理器；3. 数据与代码分离（config.json 定位一切，迁移只改 data_root）；4. 全链零删除——分拣错了就挪位置，历史进回收站/归档；5. 台账真源在 记录/，交付/归档都是副本或卡片视图。
