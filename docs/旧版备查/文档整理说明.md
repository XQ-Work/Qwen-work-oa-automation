# 采购文档整理说明

## 一、整理原则

以「采购项目」为归档单元——一个采购事项从立项到合同签订的所有文档集中存放在同一个项目文件夹内，便于追溯、审计和归档。

## 二、目录结构

```
文档整理/
├── 整理中/                        ← 待归类文件暂存区（放入后由 WorkBuddy 识别归类）
├── 采购项目档案/
│   └── 2026-001-示例项目/        ← 每个采购项目一个文件夹
│       ├── 01_事项审批/           ← 事项审批表、立项依据
│       ├── 02_供应商报价及资质/   ← 各供应商报价单、营业执照等资质
│       ├── 03_比质比价报告单/     ← 比质比价报告、评审记录
│       └── 04_采购合同/           ← 合同正本、附件、签署件
├── 采购项目台账.xlsx              ← 总索引，记录所有项目关键信息
└── 文档整理说明.md                ← 本文件
```

## 三、命名规范

### 1. 项目文件夹
格式：`年份-序号-项目简称`

示例：
- `2026-001-办公用品采购`
- `2026-002-服务器采购`
- `2026-003-空调维保服务`

### 2. 文档文件
格式：`文档类型_项目简称[_供应商].扩展名`

示例：
- `事项审批表_办公用品采购.docx`
- `比质比价报告单_办公用品采购.docx`
- `采购合同_办公用品采购_XX商贸.pdf`

### 3. 供应商材料
格式：`供应商序号_公司简称_材料类型.扩展名`

示例：
- `供应商1_XX商贸_报价单.pdf`
- `供应商1_XX商贸_营业执照.pdf`
- `供应商2_YY办公_报价单.pdf`
- `供应商2_YY办公_营业执照.pdf`

## 四、归档流程

| 步骤 | 动作 | 归档位置 |
|------|------|----------|
| ① 事项审批通过 | 创建项目文件夹，归档审批表 | 01_事项审批/ |
| ② 收集供应商报价 | 归档各供应商报价单及资质文件 | 02_供应商报价及资质/ |
| ③ 比价完成 | 归档比质比价报告单 | 03_比质比价报告单/ |
| ④ 合同签订 | 归档采购合同及附件 | 04_采购合同/ |
| ⑤ 贯穿全程 | 同步更新采购项目台账 | 采购项目台账.xlsx |

## 五、台账使用说明

`采购项目台账.xlsx` 是所有采购项目的总索引，每完成一个项目（或阶段性进展）应及时更新。

关键字段说明：

| 字段 | 说明 |
|------|------|
| 项目编号 | 与项目文件夹名一致，如 2026-001 |
| 审批状态 | 待审批 / 已审批 / 已驳回（下拉选择） |
| 归档状态 | 未归档 / 归档中 / 已归档（下拉选择） |
| 中标金额 / 合同金额 | 单位元，纯数字，自动千分位 |
| 参与供应商数 | 本次比价参与的供应商数量 |

台账内置示例行（浅紫色底纹），可直接参考格式填写，删除示例行后开始正式登记。

## 六、「整理中」文件夹使用流程

「整理中」是待归类文件的暂存区。你把文件丢进去，我来识别内容并归位。

### 操作步骤

| 步骤 | 谁来做 | 做什么 |
|------|--------|--------|
| ① 投放 | 你 | 将待整理的文件放入「整理中」文件夹 |
| ② 触发 | 你 | 对我说「帮我整理」或「整理一下整理中文件夹」 |
| ③ 扫描 | WorkBuddy | 列出所有文件，读取文件名和正文内容 |
| ④ 判断 | WorkBuddy | 判断每个文件属于哪个采购项目、哪个文档类别 |
| ⑤ 确认 | 你 | 查看分类方案，确认或提出调整 |
| ⑥ 归档 | WorkBuddy | 将文件移动到对应项目文件夹 |
| ⑦ 记账 | WorkBuddy | 更新采购项目台账状态 |

### 我能识别的文件类型

| 格式 | 识别方式 |
|------|----------|
| .docx / .doc | 读取正文文字 |
| .pdf | 提取文本内容（扫描件 PDF 会转为图片识别） |
| .xlsx / .xls | 读取表格内容 |
| .jpg / .png | 直接查看图片内容 |
| .txt / .md | 直接读取文本 |

### 小技巧

- **文件名有线索更好**：如果文件名里带项目名或供应商名（如「XX商贸报价单」），归类会更准、更快。
- **无法判断时会问你**：遇到内容不明确或归属存疑的文件，我会列出来请你指定，不会擅自移动。
- **整理完会清空**：归档完成后「整理中」文件夹会清空，方便下次使用。

## 七、注意事项

1. **一事一夹**：一个采购事项对应一个项目文件夹，不要将多个事项混放。
2. **供应商前缀**：供应商材料按「供应商序号_公司简称」前缀区分，便于核对数量和资质完整性。
3. **合同归档**：合同正本建议扫描为 PDF 归档，原件单独保管。
4. **编号一致**：台账中的项目编号与项目文件夹名保持一致，便于交叉检索。
5. **及时归档**：每完成一个环节及时归档并更新台账状态，避免事后补录遗漏。
