# 换机迁移手册（OA 自动化 · 五层工作区）

> 目标机器：Windows 10/11 + 桌面版 Office（Word/Excel）+ Edge 浏览器。
> 全程只有 3 处需要动手：拷文件、改一行配置、跑一次自检。

## 第 1 步 · 装 千问办公 并恢复对话记忆

新机器安装千问办公 → 登录同一账号 → 退出；
把旧机 `C:\Users\<你>\.qwenworkcn\` 整个覆盖过去（会话记录+长期记忆，AI 助理才能接着上下文干活）。

## 第 2 步 · 拷工作区（跳过 junction！）

```
robocopy "D:\自动备份\Qwen work\自动化（OA流程）" "D:\自动备份\Qwen work\自动化（OA流程）" /E /XJ
```

`/XJ` 关键：不跟随 junction，防止把 系统/ 的代码往 工作/ 里抄一遍。
整目录结构原样即可：`输入 工作 记录 系统 交付 归档 进度总览.xlsx`。

## 第 3 步 · 改一行配置

`系统/oa-automation/config.json` 里 `data_root`（和 `docs_root`）改成新机器实际路径，例如盘符不同：`E:/工作/自动化（OA流程）`。其余 19 个键都是相对路径，不用动。

## 第 4 步 · 装依赖

```
python -m pip install -r 系统/oa-automation/requirements.txt
cd 系统/oa-automation && npm install docx --no-save     # 仅生成 Word 文档需要
```

## 第 5 步 · 自检（缺什么它教你什么）

```
cd 系统/oa-automation
python tools/env_doctor.py          # 17 项检查
python tools/env_doctor.py --fix    # 自动重建失效的 junction（80_工具/50_模板）
```

绿 17、黄≤1（黄色=首次发草稿时会弹窗要 OA 账号密码，属正常）即为就绪。

## 第 6 步 · 首单验证

随手造一个 `事项审批（迁移测试）.pdf` 丢 `输入/` → `python intake_all.py run --selftest --inbox 某临时目录` 先干跑 → 真跑 `run` → `python -m oa_common.dashboard` 看总览出词 → 一切正常后删测试件。OA 密码会在第一次 `flush` 时弹窗录入一次，存进 Windows 凭据管理器，之后免输。

## 完整恢复清单（三件套）

| 件 | 来源 | 新机动作 |
|---|---|---|
| 代码 | GitHub 私有仓 `Qwen-work-oa-automation` | `git clone git@github.com:XQ-Work/Qwen-work-oa-automation.git`（新机器要先 `gh auth login` 重新登录+登记一把新公钥，两分钟） |
| 文档+模板 | 建议第二个私有仓 `Qwen-work-oa-docs`（待用户拍板）或随数据备份盘 | 放入 `系统/docs`、`系统/模板` |
| 业务数据 | 备份盘 `D:\自动备份\OA数据备份\最新镜像` | 拷回 `记录/ 工作/ 交付/ 归档/ 输入/ config.json` |

克隆/拷回后按上面第 3~6 步走（改 data_root → 装依赖 → doctor --fix → 首单验证）。
**日常节奏**：每次干完活跑一下 数据备份.ps1（或挂到任务计划器每天下班自动跑），代码 `git push` 一条。

## 注意

- junction 只在 NTFS 有效；工作区不要放网盘同步盘/ exFAT U盘
- 浏览器登录态（数据在 系统/运行/edge_profile）拷过去通常直接免登；失效就首跑人工登一次
- 凭据密码**不随拷贝迁移**（在旧机凭据管理器里），新机首次弹窗输入即可
- 备份策略：代码走 GitHub 私有仓库；`记录/ 交付/ 归档/` 定期 robocopy 到备份盘（含 junction 用 /XJ）
